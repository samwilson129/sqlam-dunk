SQLAM Dunk — User-Facing Functionality
Accounts
Continue as a guest to explore the game.
Sign up with email and password.
Log in and log out securely.
Return later and continue personal progress.
Each account has completely separate XP, coins, levels, solved challenges, hints, and query history.
SQL Investigation
Start the NBA Finals investigation case.
Select the next available challenge.
Read the investigation question and SQL concept being taught.
Review the available tables and columns.
Use a starter query or write custom SQL.
Run queries against the built-in basketball dataset.
Review returned rows and refine the query.
Submit the answer when the result matches the challenge requirements.
Progression
Challenges unlock sequentially.
Completing a challenge unlocks the next one.
Completing a chapter unlocks the next chapter or case section.
Previously solved challenges remain marked as complete.
Logging out does not erase progress.
Logging in as another user loads only that user’s progress.
Rewards
Correctly solving challenges awards XP and coins.
Harder challenge bands award more coins than earlier challenges.
XP contributes to the player’s level.
Completion rewards are not repeatedly granted for replaying the same challenge.
Coins are personal to the account and cannot be shared between players.
Hints
The first hint for a challenge is free.
Additional hints cost coins.
Hint prices increase with each level of detail:
Hint 1: free
Hint 2: 25 coins
Hint 3: 60 coins
The most detailed hint costs the most.
Hint usage is saved separately for each user.
One player’s hint purchases do not affect another player.
Typical Player Session
Log in or create an account.
Open the investigation case.
Choose the next unlocked challenge.
Write and run SQL.
Use the free hint if needed.
Purchase deeper hints only when necessary.
Submit the correct result.
Earn XP and coins.
Return later and continue from the saved progress point.
Important Guest Limitation
Guest mode is intended for exploration. To reliably save personal progress, XP, coins, hints, and unlocks across sessions, the player should create an account and remain signed in while playing.
